# Topological Overlap Matrix (TOM) Dissimilarity

Computes TOM dissimilarity matrix from trait matrix or harmonized
object.

## Usage

``` r
wgcna_dist(object, params)
```

## Arguments

- object:

  wide matrix or harmonized long object

- params:

  list of parameters for WGCNA routines

## Value

numeric TOM dissimilarity matrix
