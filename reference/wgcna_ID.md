# ID data frame from

ID data frame from

## Usage

``` r
wgcna_ID(object, condition_under = TRUE, annot = NULL)
```

## Arguments

- object:

  data frame containing ID information

- condition_under:

  condition has embedded "\_" if \`TRUE\`

- annot:

  annotation file (ignored if \`NULL\`)

## Value

data frame with column \`ID\` and optional column \`animal\`
